### 🧱 FUVIA
**AI-Powered Concrete Mix Design**

Replaces weeks of preliminary lab testing with instant ML predictions. End-to-end system: React frontend → FastAPI inference API → CatBoost model (R² > 0.92) → PostgreSQL data layer.

Includes ACI/ASTM input validation and an XAI engine for prediction explainability.

`Python` `FastAPI` `React` `CatBoost` `Docker` `PostgreSQL`

### 👁️ CV Pipeline
**Computer Vision · Undergraduate Thesis**

Automated material testing pipeline using YOLOv8 for real-time detection of concrete specimens under compression. Converts pixel coordinates to millimeter-scale deformation and computes modulus of elasticity automatically.

`Python` `YOLOv8` `OpenCV` `Deep Learning`
